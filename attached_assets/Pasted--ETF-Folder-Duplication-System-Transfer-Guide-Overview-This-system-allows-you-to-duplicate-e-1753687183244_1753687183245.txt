
# ETF Folder Duplication System - Transfer Guide

## Overview
This system allows you to duplicate entire n8n folders containing multiple workflows for client onboarding. Perfect for creating complete automation suites like the Pet Clinic Template with multiple interconnected workflows.

## What This System Does

### ✅ **Folder Duplication**
- Duplicates entire n8n folders (like "Pet Clinic Template")
- Copies all workflows within that folder
- Renames them with client's business name: `[BUSINESS NAME] WORKFLOW_NAME`
- Maintains folder organization structure

### ✅ **Client Personalization**
- Replaces placeholders like `{{CLIENT_NAME}}`, `{{CLIENT_EMAIL}}`
- Activates all workflows automatically
- Assigns proper folder tags for organization

### ✅ **ETF (Exchange Traded Fund) Setup**
- Creates multiple workflows per client (not just one)
- Handles complex business automation suites
- Scalable to hundreds of clients

## Core Files to Transfer

### 1. Workflow Duplicator (`tools/workflow-duplicator.js`)
This is the main engine that handles folder duplication.

**Key Functions:**
- `duplicateN8NFolder()` - Duplicates n8n folders by folder ID
- `duplicateWorkflowFolder()` - Legacy support for path-based duplication
- `getWorkflowsFromFolder()` - Retrieves workflows from specific folders

### 2. Folder Manager (`client-onboarding/server/folder-manager.js`)
Handles virtual folder organization and workflow tagging.

**Key Functions:**
- `createFolder()` - Creates virtual folder structure
- `assignWorkflowToFolder()` - Organizes workflows into folders
- `autoOrganizeAllWorkflows()` - Auto-organizes based on naming

### 3. Server Integration (`client-onboarding/server/app.js`)
Express.js server with ETF onboarding endpoints.

**Key Routes:**
- `POST /api/onboard` - Main client onboarding with ETF support
- `POST /api/onboard-etf` - Dedicated ETF endpoint
- `GET /api/folders` - Folder management

```bash

cp client-onboarding/server/app.js your-project/client-onboarding/server/
cp client-onboarding/public/* your-project/client-onboarding/public/
```

### Step 2: Install Dependencies


### Step 3: Environment Configuration

Create `.env` file:

```bash
# N8N Instance Configuration
N8N_BASE_URL=https://your-n8n-instance.com
N8N_API_KEY=your-n8n-api-key

# Server Configuration
PORT=5000

# Template Configuration (Optional)
TEMPLATE_FOLDER_ID=your-folder-id-from-n8n
```

### Step 4: Get Your N8N Folder ID

1. Go to your n8n instance
2. Navigate to your template folder (like "Pet Clinic Template")
3. Copy the folder ID from the URL: `https://n8n.../folders/OTkgImaRhmTXepG3/workflows`
4. The ID is: `OTkgImaRhmTXepG3`

## Usage Examples

### Basic ETF Client Onboarding

```javascript
const N8NWorkflowDuplicator = require('./tools/workflow-duplicator');

const duplicator = new N8NWorkflowDuplicator({
    baseURL: process.env.N8N_BASE_URL,
    apiKey: process.env.N8N_API_KEY
});

// Client data
const clientData = {
    name: "Downtown Pet Clinic",
    businessName: "Downtown Pet Clinic",  // Used for [BUSINESS NAME] prefix
    email: "info@downtownpets.com",
    phone: "+1-555-PET-CARE",
    company: "Downtown Pet Clinic LLC",
    businessType: "Pet Clinic"
};

// Duplicate entire folder
const result = await duplicator.duplicateN8NFolder(
    'OTkgImaRhmTXepG3',  // Your n8n folder ID
    clientData,
    { activate: true }
);

console.log(`Created ${result.createdWorkflows.length} workflows for ${clientData.businessName}`);
```

### Express.js Integration

```javascript
app.post('/api/onboard', async (req, res) => {
    const clientData = req.body;
    
    // Check if this is ETF setup
    const isETFSetup = clientData.workflowType === 'etf' || clientData.multipleWorkflows === true;
    
    if (isETFSetup) {
        // Duplicate entire folder
        const result = await duplicator.duplicateN8NFolder(
            'OTkgImaRhmTXepG3',  // Your template folder ID
            clientData,
            { activate: true }
        );
        
        res.json({
            success: true,
            message: `ETF Setup completed! ${result.createdWorkflows.length} workflows created.`,
            createdWorkflows: result.createdWorkflows.map(w => ({
                name: w.newName,
                url: `${process.env.N8N_BASE_URL}/workflow/${w.newId}`
            }))
        });
    }
});
```

## Frontend Form Integration

```html
<!-- ETF Onboarding Form -->
<form id="etfOnboardingForm">
    <input type="text" name="businessName" placeholder="Business Name" required>
    <input type="email" name="contactEmail" placeholder="Contact Email" required>
    <input type="tel" name="phoneNumber" placeholder="Phone Number" required>
    
    <!-- ETF Specific -->
    <input type="hidden" name="workflowType" value="etf">
    <input type="hidden" name="multipleWorkflows" value="true">
    
    <button type="submit">Create Complete Automation Suite</button>
</form>

<script>
document.getElementById('etfOnboardingForm').addEventListener('submit', async (e) => {
    e.preventDefault();
    
    const formData = new FormData(e.target);
    const clientData = Object.fromEntries(formData);
    
    const response = await fetch('/api/onboard', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(clientData)
    });
    
    const result = await response.json();
    
    if (result.success) {
        alert(`Success! Created ${result.createdWorkflows.length} workflows`);
        console.log('Created workflows:', result.createdWorkflows);
    }
});
</script>
```

## Troubleshooting

### Issue: No workflows found in folder
**Solution**: Check your folder ID is correct from n8n URL

### Issue: Single workflow created instead of multiple
**Solution**: Ensure `workflowType: 'etf'` in client data

### Issue: Workflows not activated
**Solution**: Check N8N API key has activation permissions
