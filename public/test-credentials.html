🤖 Telegram Credentials Test

Use this tool to validate your Telegram bot credentials before setting up your ETF automation.

📋 How to get these credentials:

Bot Token:

  1. Open Telegram and search for @BotFather
  2. Send: /newbot
  3. Follow prompts to name your bot
  4. Copy the token provided

Chat ID:

  1. Add your bot to the target chat/group
  2. Send a test message in that chat
  3. Visit: https://api.telegram.org/bot{YOUR_TOKEN}/getUpdates
  4. Find the "chat" → "id" field
