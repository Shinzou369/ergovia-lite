🤖 Telegram Bot Setup:

  1. Open Telegram and search for @BotFather
  2. Send /newbot command
  3. Follow the prompts to name your bot
  4. Copy the bot token provided
  5. Add your bot to the group/channel where you want notifications
  6. Send a message in that chat
  7. Visit: https://api.telegram.org/bot[BOT_TOKEN]/getUpdates
  8. Look for the "chat":{"id": value in the response

📱 Twilio SMS Setup:

  1. Sign up at twilio.com
  2. Go to Console Dashboard
  3. Find your Account SID and Auth Token
  4. Purchase a phone number in Phone Numbers > Manage > Buy a number
  5. Copy the phone number in E.164 format (+15551234567)

📧 SendGrid Email Setup:

  1. Sign up at sendgrid.com
  2. Go to Settings > API Keys
  3. Create a new API key with full access
  4. Copy the API key (starts with SG.)

🤖 OpenAI API Setup:

  1. Sign up at platform.openai.com
  2. Go to API Keys section
  3. Create a new API key
  4. Copy the key (starts with sk-)

📅 Calendly API Setup:

  1. Log in to your Calendly account
  2. Go to calendly.com/integrations/api_webhooks
  3. Click "Generate New Token"
  4. Copy the Personal Access Token
