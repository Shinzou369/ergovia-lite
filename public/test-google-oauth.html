🔐 Google OAuth Flow Test

Test Google OAuth authentication flow for ETF clients. This simulates the actual process clients will go through to connect their Google accounts.

Test Flow:
1. Configure OAuth application settings
2. Generate authorization URL
3. Redirect to Google for authentication
4. Handle callback and exchange code for tokens
5. Create N8N credentials with tokens

📋 OAuth Application Configuration

Configure your Google OAuth application settings for testing

From Google Cloud Console > APIs & Services > Credentials
Must match exactly with Google Cloud Console configuration

🔑 Required OAuth Scopes

Different Google services require different permission scopes:

Google Sheets:

  • https://www.googleapis.com/auth/spreadsheets
  • https://www.googleapis.com/auth/drive.file

Google Drive:

  • https://www.googleapis.com/auth/drive
  • https://www.googleapis.com/auth/drive.file

Google Calendar:

  • https://www.googleapis.com/auth/calendar
  • https://www.googleapis.com/auth/calendar.events

🔄 OAuth Flow Steps

Step 1: Authorization URL Generation

Generate the URL that redirects users to Google's consent screen

Step 2: User Consent

User visits Google's consent screen and grants permissions

Step 3: Authorization Code

Google redirects back with authorization code

Step 4: Create N8N Credential

Create credential in N8N with obtained tokens
